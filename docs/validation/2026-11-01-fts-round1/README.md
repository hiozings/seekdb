## 本轮实现

- TOKENIZE 默认属性直接初始化，显式属性只解析一次；有界线程本地结果复用，完整输入/解析器/collation/全文子系统代际键，失败/显式属性/超长输入走原路径。
- 局部词频容器及 IK 仲裁器去锁；停用词同字符集避免转换分配；词频原地更新。
- 对严格的裸自然语言 WHERE MATCH 省略评分及统计，保留阈值/投影/排序/布尔/跨作用域路径；短词列表批量归并。
- 外层纯 COUNT(*) 的简单 LIMIT 视图允许删除不可观察的 MATCH 排序和投影，保持行可观察/副作用/锁/其它排序等排除条件。
- 参考并适配公开 PR #2268、#1787 的部分实现；新增缓存代际和保守门控由本任务实现。未修改官方基准或启用既有默认关闭的 compact 实验。
