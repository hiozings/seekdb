# 全文索引性能优化验证（2026-10-29）

已实现三处内核热路径优化，正确性回归通过。本机12轮完整基准（每版本6轮）观测三类等权综合耗时下降 **2.17%**，但两批分别为 **+4.33%** 和 **−0.33%**，因此整体改善尚不能认定稳定，未达到50%耗时下降目标。

## 修改与定位依据

- `src/storage/fts/ik/ob_ik_char_util.h`：原分类依次检查字母、数字、中文、其他CJK，每个谓词重新解码同一字符。改为解码一次后保持原分类优先级；UTF16条件分支和原解码错误保持不变。
- `src/storage/fts/ob_ik_ft_parser.cpp`：调用者已取得字符、长度和类型，四个处理器直接使用这些参数，避免重复调用上下文取值函数。保留处理器顺序和所有处理步骤。
- `src/share/text_analysis/ob_token_stream.cpp`：在UTF8字符集处理器下，ASCII字符长度直接取1；非ASCII和其他字符集仍走原长度函数。分隔符规则、归一化和词串存储完全不变。

本环境 `perf stat` 被权限策略拒绝，未修改主机权限。瓶颈依据来自实际调用链中的重复工作及优化前后原生微基准；不能把局部微基准收益等同整个SQL链路收益。原生日志见 `micro-before.txt`、`micro-after.txt`，校验和保持一致。未改排序、倒排存储或排名算法，未引入SQL结果缓存。
