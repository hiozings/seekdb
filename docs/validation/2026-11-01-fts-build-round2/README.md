开发起点：244f6a19f。正式平台最新综合耗时下降43.124636%，得分43.124636/50；未达到满分。

## 正确性

批处理保留每批只属于一个源文档；长文档可以跨批，下一文档只在上一个已消费后获取；compact实验仍使用原标量路径。新测试覆盖批大小0/1/7/256、700词长文档、首尾空文档、分区/非分区、IK/BENG、构建后DML。

BMP直查仅用于完成初始化后的不可变字典；失败分配、异常UTF8及补充平面输入回退原字节哈希；穷举BMP与旧实现对照。

融合UTF8长度判定与分类候选：只对成功解码走快速路径；错误、空串、UTF16和不支持的字符集继续原处理。原生测试穷举Unicode码点，并比较返回码、输出长度、分类；保留异常surrogate语义。该组合已通过10/10原生目标、586项完整输出对照、9/9官方SQL套件；六轮性能测量见上表。BMP直查因端到端收益未证实已移出当前源码，实验补丁单独保留。

官方基准、固定基线、计时与评分未修改。尚无本轮提交或推送。

批处理参考并适配公开PR [#1787](https://github.com/oceanbase/seekdb/pull/1787) 的构建投影部分；本轮保留compact标量路径，并补充源文档与批次边界回归。未采用该PR的其他查询语义改动。

缓存重放实验把逐词内存申请合并为每篇文档一次申请；词字节仍深拷贝到调用方allocator，缓存淘汰不影响结果，插入顺序保持不变。10个原生目标、586项完整结果及9组官方SQL通过，性能结果见下文。移除BMP测试时误删测试main导致一次链接失败，恢复原入口后重新编译并通过；没有跳过测试。

## 最终候选选择

隔离比较batch-only与batch+融合解码+重放分配（无BMP），六轮结果：构建下降0.3086%、分词退化1.9143%、查询下降2.0358%，三类等权下降0.1434%。结果不足以证明新增两项优化收益，已将两项移出最终源码，保留实验补丁。最终只交付构建批处理与相应回归/测量支持；不将未证实收益叠加到7.640%构建改善上。上述隔离测量结束后governor均恢复。

最终源码仅修改codegen和TableScan三处内核文件。移除未证实收益的实验后重新编译，10/10原生测试、586项完整结果、9/9官方SQL均再次通过。`candidate.binary.json`和压缩结果对应最终`fts-build-final-batch`二进制，而非撤下的实验。与原始比赛二进制的完整同机对照已完成，结果如下。
